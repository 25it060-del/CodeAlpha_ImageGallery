# CodeAlpha_ImageGallery


## 🎯 Objectives
- Build a responsive image gallery using frontend technologies.
- Enhance user experience with interactive features.
- Improve skills in HTML, CSS, and JavaScript.

## ▶️ How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run `index.html` in your web browser.

## 📚 Learning Outcomes
- Responsive web design principles
- CSS styling and layouts
- JavaScript 
- Frontend project structure and organization
